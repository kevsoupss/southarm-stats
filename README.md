# Southarm.gg 
Southarm.gg is a web application for tracking player stats, match history, and goals for our Saturday soccer games. It provides a clean interface for viewing match results, analyzing player performance, and keeping track of season-long stats.
I built this project to learn Java Spring Boot, whilst also making an application that can be enjoyed by the players at the Saturday games. 

## Tech Stack

- **Backend:** Java, Spring Boot  
- **Database:** PostgreSQL  
- **Caching:** Redis  
- **Deployment:** Frontend deployed on Vercel at https://southarmstats.vercel.app/, backend deployed on Render, and database hosted on Supabase
